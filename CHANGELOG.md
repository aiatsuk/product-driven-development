# Changelog

All notable changes to this plugin. Newest first.

## 0.5.0 — 2026-09-02

- First public release of the self-contained Product Driven Development skill and plugin.
- Codex manifest in `.codex-plugin/` and Claude-compatible manifest and marketplace entry in `.claude-plugin/`.
- Bounded read-only evidence helper for named Codex, Claude, and Grok sessions, with unit tests.
- Public-content check that scans only tracked files and rejects private or machine-specific material.
